# WP-102 — Host-Only Pipeline

For how this fits into the rest of the system (composition root, adapter
boundary, dependency direction), see `techdocs/ARCH.md`. For environment
setup, see `SETUP.md`.

## What it is

The host-only voice path, with no dialogue graph, no policy, and no
storage in the loop:

```text
USB microphone
    ↓
audio capture
    ↓
faster-whisper (STT)
    ↓
Ollama (LLM)
    ↓
Piper (TTS)
    ↓
host speakers
```

This is the simplest end-to-end path in the repository and predates the
WP-103 dialogue graph. It exercises the STT, LLM, and TTS adapters
directly without going through `composition/bootstrap.py`'s graph wiring.

## Running it

```bash
python -m scripts.run_wp102
```

This requires the configured Ollama, faster-whisper, Piper, microphone,
and speaker/audio output all present and working — see `SETUP.md` steps
4–6 and `PREFLIGHT.md` §3–5 to verify each one before running.

For a captured evidence run:

```bash
python -m scripts.run_wp102 > evidences/live_run_wp102.txt 2>&1
```

Confirm the evidence contains successful initialization, a transcript, a
response, and stage timings.
